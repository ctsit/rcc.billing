# Creates a invoice_line_item data from invoice_line_item_communications_data

Creates a invoice_line_item data from
invoice_line_item_communications_data

## Usage

``` r
invoice_line_item_df_from(invoice_line_item_communications)
```

## Arguments

- invoice_line_item_communications, :

  data that follows the format of
  invoice_line_item_communications_test_data located in R/data.R

## Value

invoice_line_item dataframe

## Examples

``` r
if (FALSE) { # \dontrun{
invoice_line_item_df_from(invoice_line_item_communications_test_data)
} # }
```
