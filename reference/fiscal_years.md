# fiscal_years

A dataframe of fiscal years and labels from 2019-2020 to 2039-2040

## Usage

``` r
fiscal_years
```

## Format

A data frame with 21 rows and 2 variables:

- `csbt_label`:

  character A string representing the fiscal year range, in the format
  YYYY-YYYY

- `fy_interval`:

  double A lubridate interval object from the start of the UF fiscal
  year (July 1) to the end
